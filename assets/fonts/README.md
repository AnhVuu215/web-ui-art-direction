# Specimen font

Be Vietnam Pro Regular, Medium and Bold are self-hosted here so Vietnamese renders do not depend on a font CDN.

Source: [Google Fonts Be Vietnam Pro directory](https://github.com/google/fonts/tree/main/ofl/bevietnampro), retrieved 2026-10-08. Original filenames are preserved. Font credits and reserved names are in [OFL.txt](OFL.txt).
